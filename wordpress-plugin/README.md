# Chatnelo – WordPress / WooCommerce plugin

- `plugin/` – the plugin as published on WordPress.org (slug `chatnelo-ai-chatbot-for-woocommerce`)
- `assets/` – WordPress.org listing images (icon, banner)

Publishing is automatic: any change here is deployed to WordPress.org by
`.github/workflows/wordpress-plugin-deploy.yml`. Bump `Version` in the plugin
header and `Stable tag` in `readme.txt` for every release.
